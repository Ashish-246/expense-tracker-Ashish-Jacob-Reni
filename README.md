# Expense Tracker

A lightweight, responsive expense tracker built with vanilla HTML, CSS, and JavaScript. All data is persisted locally in the browser using `localStorage`, with zero external dependencies.

## Features

- **Transaction Management:** Add, edit, and delete income and expense transactions.
- **Financial Overview:** Real-time tracking of total balance, income, and expenses.
- **Analytics:** Monthly spending breakdowns and category-wise summaries.
- **Filter & Search:** Filter transactions by type and category.
- **Data Persistence:** Automatically saves data using browser `localStorage`.
- **UI & UX:** Form validation with error handling and a responsive dark-mode interface.

## Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Responsive Design / Dark Mode)
- **Logic:** Vanilla JavaScript (ES6+)
- **Storage:** Web Storage API (`localStorage`)

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Ashish-246/expense-tracker-Ashish-Jacob-Reni.git
cd expense-tracker-Ashish-Jacob-Reni
```

### 2. Run the App

No build steps, runtimes, or package managers are required. You can launch the application using either of the following methods:

- **Direct Open:** Double-click `index.html` or right-click it and open it in your default browser.
- **VS Code Live Server:** Open the project in VS Code, right-click `index.html`, and select **Open with Live Server**.
